# IMDb Top 250 Movies Scraper

This Python-based web scraper fetches data for the top 250 movies listed on IMDb, including details like title, year, IMDb rating, and more. The scraped data is then neatly organized into a Pandas DataFrame, which can be easily used.

---

## Technologies Used

- **Python 3.x**
- **Beautiful Soup 4**: For parsing HTML and extracting data.
- **Pandas**: For data manipulation and analysis.
- **Selenium**: For automating web browser interaction.
- **WebDriver Manager**: For automatically downloading and managing browser drivers (e.g., ChromeDriver, GeckoDriver).

---

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have Python 3.11.10 installed. You can download it from [python.org](https://www.python.org/).

### Installation

1.  **Clone the repository:**

    ```bash
    git clone https://github.com/bkandh30/imdb-web-scrape.git
    cd imdb-web-scrape
    ```

2.  **Install the required Python packages:**

    ```bash
    pip install -r requirements.txt
    ```

---

## Usage

To run the scraper, simply execute the main Python script:

```bash
python3 main.py
```
